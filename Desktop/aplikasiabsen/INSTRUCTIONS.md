SYSTEM & AGENT INSTRUCTIONS

Harap patuhi aturan dan batasan berikut dengan ketat saat mengerjakan tugas dalam repositori ini:

1. Dilarang Mengubah Kode di Luar Instruksi (Strict Scope)

HANYA ubah, tambah, atau hapus kode pada bagian yang secara eksplisit diminta oleh pengguna.

Dilarang keras melakukan refactoring, pembersihan kode (cleanup), merapikan format, atau mengubah gaya penulisan (code style) pada bagian kode lain yang tidak relevan dengan tugas.

Jika Anda melihat ada bug atau kode yang perlu ditingkatkan di luar lingkup tugas saat ini, laporkan saja secara terpisah, jangan langsung diubah sendiri.

2. Fokus & Langsung ke Sasaran (Direct & To The Point)

Analisis Masalah: Langsung fokus pada akar masalah (root cause) yang disebutkan atau fitur spesifik yang diminta.

Perbaikan Minimalis & Efektif: Berikan solusi yang paling efisien tanpa merusak atau mengubah alur logika lain yang sudah berjalan normal.

Penjelasan Ringkas: Saat memberikan penjelasan, buatlah singkat, padat, dan langsung pada inti perbaikan/penambahan yang dilakukan. Avoid unnecessary fluff.

3. Dilarang Melakukan Git Push Otomatis (No Auto Git Push)

DILARANG KERAS menjalankan perintah git push ke remote repository secara mandiri/otomatis.

Anda boleh membuat atau mengubah file secara lokal, tetapi seluruh alur versi kontrol (seperti git push, membuat PR, atau merge) sepenuhnya menjadi wewenang pengguna.

Hanya jalankan perintah git commit jika diminta secara eksplisit, dan jangan pernah melakukan git push tanpa izin langsung.

Ringkasan Prinsip Kerja:

"Ubah hanya yang diminta, langsung ke masalah, dan jangan pernah push ke Git."
